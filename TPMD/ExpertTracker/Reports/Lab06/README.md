# Лабораторна №6 — RBAC, камера та GPS

У гілці lab-06 підготовлено навчальну реалізацію:
- локальний вхід з користувачами `owner` і `accountant`;
- хешування PBKDF2-SHA256 із випадковою сіллю; паролі **не зберігаються відкрито**;
- `Owner` може видаляти витрати, `Accountant` — ні; перевірка є також у команді `DeleteAsync`;
- `IDeviceService` для MediaPicker/Geolocation, перевірка runtime permissions;
- шлях фотографії та координати зберігаються в таблиці Expenses;
- додано AndroidManifest дозволи.

**Демо лише для практикуму (не для реального використання):**
- owner / demo-owner-2026
- accountant / demo-accountant-2026

**Не перевірено:** збірка, камера й GPS на фізичному пристрої, різні ролі, відмова у дозволі. Потрібні скриншоти й журнал 3 реальних LLM-звернень. Викладач має погодити спосіб використання GPS/камери за варіантом №2.

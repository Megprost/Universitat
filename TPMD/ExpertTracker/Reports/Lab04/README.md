# ЛР №4 — Логування та обробка помилок

Реалізовано ILogger<T> через DI, файловий провайдер у AppDataDirectory/experttracker.log, рівні Information/Warning/Error/Critical, try/catch в Repository, глобальні обробники AppDomain/TaskScheduler. Поведінку при контрольованій помилці та лог-файл потрібно перевірити в Visual Studio/на пристрої. Записи для LLM-журналу й скриншоти після реальних тестів.

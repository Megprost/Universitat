# Лабораторна робота №2 — короткий протокол перевірки

**Варіант:** 2, ExpertTracker.  
**Тема:** навігація, життєвий цикл та відновлення стану .NET MAUI.

## Фактично реалізовано

- `ExpensesPage → ExpenseDetailsPage` через Shell `GoToAsync` з параметром `id`.
- `IQueryAttributable` для завантаження потрібної витрати.
- `ILifecycleAware` для відокремлення логіки від code-behind.
- Події `Window.Created`, `Activated`, `Deactivated`, `Stopped`, `Resumed`, `Destroying`.
- `Preferences.Default` для трьох полів чернетки; після виправлення 25.10.2026 чернетка також записується на зміну кожного поля.
- Витрати поки лишаються в пам'яті, SQLite додано у ЛР №3.

## Що підтверджено студентом

- `Rebuild All: 1 succeeded, 0 failed` для чотирьох target frameworks.
- Запуск Windows-версії.
- Додавання двох витрат на 5 000 і 12 000 грн, загальна сума 17 000 грн.
- Перехід до деталей обох витрат з правильними назвами, категоріями, датами й сумами.
- Після виправлення кольорів три поля `Entry` відображаються читабельно.

## Що ще перевірити для звіту

1. Зробити скриншот незавершеної чернетки (наприклад, `Тест стану / Транспорт / 2500`), **не натискати «Додати витрату»**.
2. Згорнути й повернути програму; перевірити вміст полів.
3. Повністю закрити програму та повторно запустити; зняти другий скриншот із відновленими полями.
4. `View → Output → Debug`: знайти `[Lab02]` і записати фактичну послідовність Window lifecycle.
5. За методичкою потрібна перевірка на емуляторі або пристрої; успішна компіляція Android не доводить Android-запуск.

# Журнал LLM — лабораторна №2

## Запис 1. Проєктування реалізації

**Запит користувача:** «Все, тепер переходимо до лаби 2, реалізовуй».

**Стислий зміст відповіді:** проаналізовано лабораторну №2 та структуру наявного ExpertTracker; підготовлено другу сторінку, Shell-навігацію за id, контракт ILifecycleAware, збереження чернетки через Preferences і Window lifecycle events.

**Рішення студента та обґрунтування:** заповнюється **після** перевірки та прийняття реалізації студентом. Не слід видавати ще не перевірений код за успішний тест.

## Наступні записи

Після фактичного тестування додати ще мінімум два **реальні** звернення до LLM (наприклад, аналіз журналу Window lifecycle, виправлення маршрутизації/відновлення чернетки). Кожне: запит → відповідь стисло → рішення та обґрунтування.

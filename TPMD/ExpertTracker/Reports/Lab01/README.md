# Лабораторна робота №1 — матеріали для здачі

**Тема:** Проєктування базової архітектури мобільного додатка на платформі .NET MAUI за патерном MVVM з використанням LLM-асистента.  
**Варіант 2:** трекер бізнес-витрат для ФОП.  
**Проєкт:** `ExpertTracker`.

## Реалізація

Код розміщено у `../../ExpertTracker/` (відносно цієї папки). Реалізовано клас `Expense`, `ExpensesViewModel : ObservableObject`, спостережувану колекцію, `RelayCommand`, XAML-екран, прив'язку `BindingContext` та реєстрацію DI.

## Фактична перевірка

- Успішна збірка чотирьох цільових платформ за повідомленням Visual Studio: `Build: 1 succeeded, 0 failed`.
- Запуск **Windows Machine**.
- Початковий екран: порожній список і 0 грн.
- Валідація: повідомлення «Введіть назву та категорію.».
- Два записи: 1 500 грн та 18 500 грн; загальна сума — 20 000 грн.

**Обмеження:** Android-емулятор/фізичний пристрій не підтверджений скриншотами. Поточна ціль — .NET 10 (методичка вказує .NET 8). Ці розбіжності необхідно врахувати перед остаточною здачею.

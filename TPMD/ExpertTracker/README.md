# ExpertTracker — Лабораторна робота №6

**Дисципліна:** Технології розробки мобільних додатків на C#  
**Варіант 2:** трекер бізнес-витрат ФОП.  
**Стек:** .NET MAUI 10, C#, MVVM, CommunityToolkit.Mvvm, SQLite, xUnit, Moq.

## Функціональність лабораторних №1–6

1. MVVM: список і додавання бізнес-витрат.
2. Shell-навігація, передавання ID, події життєвого циклу та Preferences для чернетки.
3. SQLite, репозиторій, асинхронні CRUD-операції та постійне збереження.
4. ILogger, файловий журнал та обробка помилок.
5. xUnit, Moq, unit- та інтеграційні SQLite-тести.
6. Локальна автентифікація, ролі Owner/Accountant, фотографування чека та GPS.

## Ролі

| Дія | Owner (власник ФОП) | Accountant (бухгалтер) |
|---|---|---|
| Перегляд, додавання, редагування витрат | Так | Так |
| Видалення витрати | Так | Ні |
| Фото чека та координати витрати | Так | Так |

Для навчального тесту після першого запуску створюються демонстраційні користувачі у SQLite з хешем PBKDF2-SHA256 та випадковою сіллю:

- `owner` / `demo-owner-2026`
- `accountant` / `demo-accountant-2026`

Ці паролі призначені тільки для демонстрації і не мають використовуватися у реальних фінансових застосунках.

## Камера та GPS

У деталях витрати кнопка «Сфотографувати чек» використовує `IDeviceService` / `MediaPicker` та зберігає файл у приватному каталозі застосунку, а шлях — у SQLite. Кнопка «Зберегти GPS-координати» зберігає широту й довготу у відповідному записі. Доступ запитується під час використання відповідної функції, а відмова обробляється без аварійного завершення.

Для реального тестування камери та GPS рекомендовано Android-пристрій; у емуляторі може знадобитися налаштувати імітацію камери та координат.

## Запуск

Відкрити `ExpertTracker.slnx` у Visual Studio та запустити `Windows Machine` для перевірки ролей і UI; для апаратних функцій використовувати Android-пристрій/емулятор. Не використовувати реальні чеки, особисті фінансові дані чи фактичні домашні координати в скриншотах звіту.

Для тестів:

```powershell
cd D:\Universitat\TPMD\ExpertTracker
dotnet test .\ExpertTracker.Tests\ExpertTracker.Tests.csproj --logger "console;verbosity=normal"
```

# ExpertTracker — лабораторна №6 (варіант 2)

## Реалізовано у коді
№1 MVVM, №2 Shell / Preferences, №3 SQLite / Repository, №4 ILogger / файл логів, №5 xUnit / Moq / SQLite-тести.
№6: локальна автентифікація користувачів SQLite, PBKDF2-SHA256 + сіль, ролі Owner і Accountant. Власник може видаляти витрати, бухгалтер — ні; перевірка в інтерфейсі та команді. Фото чека через IDeviceService/MediaPicker; GPS через IDeviceService/Geolocation; runtime permissions та окремі повідомлення при відмові.

## Тільки навчальні облікові записи
- owner / demo-owner-2026
- accountant / demo-accountant-2026

Паролі демонстраційні — не застосовувати для реальних даних. Для тестування використовувати вигадані витрати та несправжні чеки.

Виконати Rebuild Solution, тестування обох ролей, заборони видалення для Accountant, фото/GPS та відмови в дозволі на фізичному Android. Виконати dotnet test тестового проєкту.

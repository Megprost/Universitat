# ExpertTracker — Лабораторна робота №2

**Дисципліна:** Технології розробки мобільних додатків на C#  
**Варіант 2:** Трекер бізнес-витрат ФОП  
**Технології:** C#, .NET MAUI 10, MVVM

## Реалізація: Навігація та збереження стану

- Shell-навігація між списком і деталями витрати за ID.
- `IQueryAttributable` отримує параметр маршруту.
- `ILifecycleAware` відділяє події сторінки від логіки ViewModel.
- Події життєвого циклу вікна та `Preferences` для збереження чернетки.

## Запуск і перевірка

Відкрити `ExpertTracker.slnx`, запустити застосунок, перевірити перехід до деталей і відновлення чернетки після повторного запуску.

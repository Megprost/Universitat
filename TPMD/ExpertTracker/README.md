# ExpertTracker

Лабораторна робота №1 з дисципліни «Технології розробки мобільних додатків на C#».

**Варіант 2:** Трекер бізнес-витрат для фізичної особи-підприємця.

## Мета

Розробити базову архітектуру мобільного застосунку на .NET MAUI за патерном MVVM із використанням LLM-асистента.

## Технології

- C#
- .NET MAUI
- MVVM
- CommunityToolkit.Mvvm (планується підключити)
- Git

## Функціональність

Застосунок призначений для обліку бізнес-витрат ФОП. Передбачено введення витрат, їх відображення у списку та обчислення загальної суми.

## Стан розробки

Створено проєкт, каталоги MVVM та модель Expense. Інші компоненти перебувають у розробці.

Поточна версія проєкту — .NET 10. Методичка передбачає .NET 8; відповідність цієї вимоги ще потребує вирішення.

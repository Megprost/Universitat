# ExpertTracker — Лабораторна робота №3

**Дисципліна:** Технології розробки мобільних додатків на C#  
**Варіант 2:** Трекер бізнес-витрат ФОП  
**Технології:** C#, .NET MAUI 10, MVVM

## SQLite та операції CRUD

- SQLite-база витрат у `FileSystem.AppDataDirectory`.
- `IExpenseRepository` та `DatabaseService` з асинхронними операціями.
- Додавання, перегляд, редагування й видалення записів.
- Перевірка збереження даних після повторного запуску.

## Запуск

Відкрити `ExpertTracker.slnx` у Visual Studio з .NET MAUI, зібрати проєкт і перевірити функції роботи №3.

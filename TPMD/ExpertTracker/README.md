# ExpertTracker — Лабораторна робота №6

**Дисципліна:** Технології розробки мобільних додатків на C#  
**Варіант 2:** Трекер бізнес-витрат ФОП  
**Технології:** C#, .NET MAUI 10, MVVM

## Ролі користувачів, фото та GPS

- Локальна авторизація з ролями `Owner` і `Accountant`.
- Обмеження видалення витрат залежно від ролі.
- Фотографування чеків через `MediaPicker`.
- Отримання координат через `Geolocation` із перевіркою дозволів.

## Запуск

Відкрити `ExpertTracker.slnx` у Visual Studio з .NET MAUI, зібрати проєкт і перевірити функції роботи №6.
